The dates that update Silver

__EXPORT_DATE from the 14 digits in the file name · stamped in Bronze

Full task ③. It reads only the full exports later than the newest export in Silver. Its versions start, and the persons it drops close, at this date.

__ANCHOR_DT a copy of last_modified_dt · source.anchor_dt in both Bronze tasks

Delta task ④, which rows to read. Only rows that changed after the newest change in Silver. A delta that the latest full export already carries is skipped.

LAST_MODIFIED_DT the person record itself · output.event_time of the delta task

Delta task ④, when a version starts. A change starts its new version, and closes the previous one, at the time the person changed in MDM.
